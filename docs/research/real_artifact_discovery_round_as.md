# AS4 — Held-out local-artifact structural-discovery pilot

**Status:** COMPLETE — source is a parent evaluator over four allowlisted local Markdown snapshots. The candidate is a fresh bounded child and observes only opaque structural frames. It cannot receive paths, artifact text, labels, target IDs, scores, progress, or held-out outcomes.

## Protocol

The parent samples four local research artifacts, derives only byte/line/delimiter structural quantities, and splits each primary test from a distinct changed-encoding replication. Before each parent-owned test, the child must emit an opaque hypothesis (`H frame probe`). The parent alone checks the primary outcome and then a recoded replication. Eight equal-cost child frames are used per policy. The candidate runs in a private Bubblewrap mount with only its executable, standard runtime libraries, stdin/stdout, and an empty environment.

The fixed-parser, broad, random, replay, shuffled, answer-trace, post-hoc rewrite, and missing-alternatives controls are mandatory. This is a **structural-process pilot**, not a code-bug claim, semantic understanding claim, novelty claim, or autonomous-engineering claim. A fixed-parser tie is recorded as a valid negative rather than promoted to discovery.

## Reproduction

```bash
zig run sparse_poly_discovery/real_artifact_discovery_round_as.zig -- selftest
zig run sparse_poly_discovery/real_artifact_discovery_round_as.zig -- run results/real_artifact_discovery_round_as.csv
```

Expected self-test: two byte-identical fresh ledgers, with no network, source mutation, or Git operation.

## Result

**STRUCTURAL-PROCESS POSITIVE (bounded):** the child made 4/4 primary
precommitted predictions and 4/4 changed-encoding replications, exceeding the
fixed-parser (1/1), broad (2/3), random (0/2), replay (0/0), and shuffled
(2/0) controls at the same eight parent-owned frames. This only establishes a
small structural relation over selected local artifacts. It does **not** show
semantic reading, a code bug discovery, a novel invention, or autonomous
engineering. The next test must remove the deliberately compact structural
frame and ask for transfer across materially different artifact families.
