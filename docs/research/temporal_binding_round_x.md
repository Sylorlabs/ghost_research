# Round X X2 — Emergent Temporal Binding

**Verdict: VALID NEGATIVE.** A small temporal-binding signal appeared, but the
experiment does not establish organism-born temporal form. The mutable binder
made 181/1,344 private lag errors, five fewer than the best equal-cost static
control (186) and thirteen fewer than random buffering (194). That margin is
small, and all three methods failed identically under a raw recoding because a
harness-fixed byte-change decoder supplied the decisive comparison operation.

## Question and contract

This local, non-language experiment asked whether 24 organism-owned bytes could
develop an intervention/consequence binder over asynchronous raw byte fields.
The bytes affect intervention order, oscillator phase, sampling time, lag vote
accumulation, and their own later mutation. The exact same initial procedure
enters every evaluator-private world; private seeds initialize world physics
only. No task label, semantic port, body map, lag answer, transcript, text
model, embedding, named feature, or Ghost solution state enters the binder.

The evaluator freezes the procedure before 32 fresh worlds in each of seven
conditions: new delay distributions, asynchronous per-field arrival, organ
replacement, distractors, raw permutation, bijective byte recoding, and
actuator remapping. Six anonymous actuators produce delayed changes across
eleven raw cells. Every scored arm receives 24 interactions per world.

Controls are fixed lag, random buffering, replay, equal-size static coverage,
no probing, binder-byte ablation, and a private supplied-alignment ceiling.
The canonical CSV also attacks evaluator-seed access, hidden lag labels,
post-freeze edits, transcript memory, byte bloat, recoding, deterministic replay,
and the fixed decoder itself.

## Result

| arm | lag errors / 1,344 | error rate |
|---|---:|---:|
| supplied private ceiling | 0 | 0.00% |
| mutable 24-byte binder | 181 | 13.47% |
| equal-size static | 186 | 13.84% |
| random buffer | 194 | 14.43% |
| fixed lag | 1,155 | 85.94% |
| no probe / binder ablation | 1,158 | 86.16% |
| replay | 1,160 | 86.31% |

The mutable binder was exact under new delays, organ replacement, distractors,
raw permutation, and actuator remapping. It made 16/192 errors under asynchronous
fields, versus 21 for equal-static and 19 for random buffering. This is a real
but weak scheduling signal: adaptive byte state improved asynchronous binding
by five decisions relative to static coverage.

Raw recoding caused 165/192 errors for the mutable, static, and random arms.
That shared collapse is dispositive. The procedure did not invent a comparison
that survived a new encoding; it depended on the harness operation `raw_byte !=
baseline_byte`. The harness also enumerated candidate delays using scheduler
ticks. Those operations installed the useful temporal form that the experiment
was supposed to make organism-owned.

## Why the verdict is negative

The numerical win does not pass the Round X acceptance gate:

- The five-error advantage over equal-static is too small to support a broad
  mechanism claim from one deterministic synthetic family.
- The binder collapses under bijective recoding, so its evidence is not an
  encoding-invariant causal relation.
- Fixed baseline comparison supplies a distance/change predicate.
- The universe scheduler supplies ordered ticks and bounded lag slots. The
  organism mutates phase and sampling, but does not invent the clock domain.
- The decoder aggregates per-lag changed-cell votes. That is already a temporal
  response-binding shape, even though its parameters are mutable.

The attack ledger therefore marks `metric_leak_detected` and
`decoder_bias_detected` as `FAIL_CLAIM`. These are experimental claim failures,
not software failures. X2 cannot unlock earned experiment inheritance.

## What was genuinely learned

Intervention timing contains enough local information for a tiny mutable byte
procedure to outperform matched static/random schedules on asynchronous fields.
But temporal binding cannot be claimed while the harness decides what counts as
a change and presents ordered candidate lags. The next angle must place raw
event storage and executable comparisons in the organism medium itself. It
should earn persistence only through later viability, and evaluation should
alter encodings in ways that preserve environmental causality while destroying
any fixed byte predicate.

## Immutable physics and limitations

The harness unavoidably supplies sequential execution, bounded memory, raw byte
transport, intervention delivery, energy/interaction accounting, and evaluator
privacy. It additionally supplies six actuator opportunities, eleven raw cells,
a 40-tick horizon, and an eight-tick maximum delay. These are strong synthetic
physics, not evidence of open-ended time, continuous embodiment, intelligence,
or autonomous goals.

Ghost contributes only the discipline: mutable binder state is Sigil scratch,
procedure bytes freeze before private worlds, and the deterministic CSV is the
snapshot. No Rune, shard, VSA/LLM path, menu, answer trace, or Ghost file was
imported or changed.

requires the conservative negative verdict, and checks the metric and causal
