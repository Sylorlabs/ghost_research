# Round AA / AA3 — organism-selected self-target

**Verdict: LIMITED FOUNDATION.** Charged causal receipts selected the
evaluator-private bottleneck in **24/24** independent cohorts, compared with
**12/24** for the strongest ordinary control (receipt frequency), **5/24** for
random selection, and **2/24** for cost, digest-byte, address, and fixed-slot
controls. The selected frozen target raised fresh hidden resource from
**30,680** to **37,640**; removing that target modification returned the result
exactly to 30,680. Storage recoding retained 24/24 selection.

This establishes a narrow, answer-free target-selection and old/new evaluator
foundation. It does **not** establish autonomous self-improvement. The fixture
supplies eight opaque component boundaries and generic removal/restoration
intervention axes. The organism selected among those partitions; it did not
invent the partitions, invent an implementation, install a change, or improve
the machinery that selected the target.

## Question and hard boundary

Can an organism use only its own charged causal X-ray/material receipts to
select which opaque internal machinery component is responsible for a resource
bottleneck, without a prompt, target name, component address, fixed request
packet, human-selected target, semantic score, or evaluator answer?

Each of 24 cohorts contains eight opaque byte-identified internal components.
Their storage locations are independently permuted. Human-readable policy names
are written only after evaluation and never enter selection. The public side
receives only calibration receipts containing:

- content digest;
- aggregate effect under removal;
- aggregate effect under generic restoration;
- independent repeat and contradiction counts;
- charged intervention cost.

It never receives the private bottleneck identity, hidden-world scores, target
rank, distance to the target, implementation menu, or per-candidate hidden
result. There is no LLM, text/token model, embedding, neural or neuro-symbolic
path, named task feature, semantic port, answer trace, or preloaded Rune.

## Method

For every opaque component, the organism pays for removal and restoration in
twelve calibration contexts. It ranks receipts by reproducible restoration
effect, contradiction burden, repeat evidence, and cost. Selection freezes
before sixteen disjoint hidden contexts per cohort are generated.

The evaluator separately knows the actual causal bottleneck and uses it only
for post-freeze accounting. It prepares equal-start snapshots:

```text
old organism       same mine + evidence + budget
candidate organism same mine + evidence + budget, selected target changed
ablated candidate  candidate target change removed
```

AA3 does not synthesize the target change. The candidate resource column is a
sealed evaluator foundation representing the consequence available at the
selected component; AA2/AA4 must provide an independently forged executable
change before any self-improvement claim is possible.

## Results

All target policies receive the same 4,608 charged calibration interventions
across 24 cohorts.

| Selection policy | Private bottleneck matches | Fresh resource | Interpretation |
|---|---:|---:|---|
| causal receipts | **24/24** | **37,640** | limited positive |
| receipt frequency | 12/24 | 34,319 | strongest ordinary target control |
| random | 5/24 | 32,456 | control |
| cheapest | 2/24 | 31,843 | control |
| opaque digest byte | 2/24 | 31,807 | name surrogate control |
| storage address | 2/24 | 31,943 | control |
| fixed slot | 2/24 | 31,943 | control |
| private oracle | 24/24 | 37,640 | invalid ceiling |
| causal after storage recoding | **24/24** | **37,640** | encoding control |

The old organism totals 30,680 resource in every comparison. Target ablation
returns every candidate policy to exactly 30,680. Thus the reported candidate
gain is attached to the selected component rather than differing starts,
budgets, mines, or hidden partitions.

## Hostile checks

The canonical ledger records these gates:

- private target order changes by cohort and is absent from receipts;
- no component name, semantic label, target grammar, or request schema enters
  selection;
- duplicate receipt digests cannot manufacture independent repeat evidence;
- calibration and hidden context seeds are disjoint;
- private bottleneck identity and hidden scores have no public channel;
- the observer is read-only;
- old and candidate share starting snapshot, mine, evidence, and budget;
- selection and candidate freeze before hidden context generation;
- target ablation returns candidate performance exactly to the old snapshot;
- a failed candidate rolls back to a byte-identical old snapshot;
- every intervention and component cost is charged, discouraging bloat;
- storage permutation/recoding cannot change content/evidence identity;
- two fresh executions are byte-identical;
- no LLM, text, token, embedding, neural, neuro-symbolic, or semantic-score path
  exists.

## What remains human-installed

This experiment deliberately exposes the next honesty boundary. Humans supplied:

- the eight-component decomposition;
- what constitutes a removal and restoration intervention;
- the raw resource consequence;
- the calibration/hidden partition protocol;
- the immutable evaluator and accounting physics.

Consequently, the 24/24 result shows that causal evidence can reliably choose
a target **when candidate causal units already exist**. It does not show that
the organism created its own responsibility partitions. That limitation makes
the verdict `LIMITED FOUNDATION`, not a general-intelligence or autonomous-
improvement positive.

## Dependency consequence

AA3 supplies the frozen equal-cost evaluator and demonstrates autonomous target
selection within an opaque supplied decomposition. AA4 must remain gated on
AA1 and AA2. Release additionally requires AA2 to deliver a genuinely internal
forged executable change derived from AA1 evidence. Integration must preserve:

1. organism-owned target choice;
2. old/new freeze before fresh evaluation;
3. target ablation;
4. rollback;
5. equal total experiment-plus-forge cost;
6. evaluator isolation.

AA3 alone authorizes no self-improvement claim.
