# Research Round 2026-07-18c (Round AM) — higher-order causal relevance

**Status:** PARTIALLY LANDED — AM1 valid negative; AM2 and AM4 foundation positives; AM3 gate ready. AM5 is ready; AM6 remains gated pending AM5.

## Premise

AL shows that static causal-effect fingerprints collapse to a fixed vector matcher and binary context segmentation collapses to fixed last-consequence routing. Relevance must instead depend on a richer structure: how interventions alter *later transitions, dependencies, and recoveries*. Round AM tests whether an organism can construct and use multi-step causal motifs and intervention topology that generalize beyond fixed static matching.

The declared frozen substrate remains: uniform raw transport, bounded generic variation/execution, resource accounting, append-only provenance, sealed pre-registered hidden worlds, and post-run evaluation. It supplies no task label, target, world-family identity, semantic decoder, static similarity matcher, regime key, change-point score, experiment menu, answer trace, intermediate reward/uncertainty, or evaluator feedback. No LLM, text/token prediction, embeddings, neuro-symbolic wrapper, or solution memory is permitted.

## Acceptance standard

A **foundation positive** requires an organism-built multi-step causal relevance structure to beat equal-cost fixed effect-vector matching, last-consequence routing, fixed temporal motifs, random, replay, shuffled history, and fixed graph controls on hidden worlds with private recoding and causal-law shifts. It must be necessary by ablation, answer-scrubbed, provenance-traced, and not contain target, label, world ID, supplied graph/motif, or a human router.
