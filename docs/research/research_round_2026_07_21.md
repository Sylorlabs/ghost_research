# Research Round 2026-07-21 (Round AW) — real multi-task milestone attempt

**Status:** LIVE — 0/3 complete.

## Premise

The record now contains many positives, valid negatives, and retractions. AW
turns that history into **method memory**, never an answer store, and attempts
the first serious integrated milestone: a non-LLM inventor must use Zag or
Zagscript scratch tools over several sealed, genuinely existing local artifacts
and beat equal-budget controls. A tie, leak, fixed-rule explanation, or failure
to transfer is negative—not a foundation win.

## Evidence carried forward

- Representability is a gate; aim can help only once an adequate tool/language
  can represent the relevant distinction.
- Accumulated failures should propose discriminating tests or tool repairs, not
  inject historical task answers.
- Broad fixed coverage remains strong and has beaten learned allocation at
  scale; every policy receives literal equal budgets.
- AS3/AS4 show why shared evaluator code, unequal time, literal curves, and
  answer channels invalidate apparent wins.
- AV establishes operational native-Zag repair over real source but no learned
  advantage because a strong fixed scanner tied.

## Non-negotiable boundary

- No LLM, embeddings, internet answer lookup, credentials, evaluator score or
  progress channel, hidden task text, source overlap, or task-answer memory.
- Method memory stores only provenance-bound, general lessons and marks false or
  retracted lessons untrusted; it never stores task IDs, expected output, heldout
  paths/hashes, solution code, or answer-shaped score rules.
- Candidate-generated tools are native Zag or Zagscript only, run in a restricted
  worker over approved copies. No Python path participates.
- Candidate, worker, corpus/evaluator, and audit remain separate roles. Scores
  and curves are derived from receipts after the run.

## Landing protocol

Each agent edits only its named source, CSV, and report. The coordinator fresh
builds/replays, updates this ledger/TOC/index, commits scoped files, and then
runs one integrated adversarial trial. AW closes positive only if the complete
system beats strong equal-budget controls across multiple held-out real tasks,
transfers an earned tool/lesson, and survives an independent reduction audit.
