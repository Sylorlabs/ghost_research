# Research Round 2026-07-16 (Round AD) — open-ended organism construction

**Status:** GATED — AD1/AD2/AD3 replayed as valid negatives; AD4–AD6 remain blocked.

**Goal:** Test the strongest remaining boundary without disguising more human
design as organism autonomy. The organism begins with only mutable matter in a
minimal causal medium. It must create its own higher-level interpreters,
representations, experiments, challenges, and improvement objectives from
resource consequences. A bootstrap mechanism is unverified, has no origin
privilege, and must be replaceable or retireable.

The only permitted human-installed exterior is: lower-level deterministic
causal transport/computation, finite resource accounting, sandbox and
provenance, evaluator-private fresh worlds, and external authority/safety.
These are enforcement conditions, not organism tools. The experiments may not
install named tasks, target functions, task family, semantic ports, component
tables, fixed encodings, fixed instruction/opcode meanings above the raw
medium, mutation or candidate menus, implementation requests, intermediate
correctness/novelty/reward score, answer traces, oracle-guided selection,
preloaded experience/Rune, LLM/text/token prediction, embeddings, or
neuro-symbolic machinery.

## Evidence standard

A positive must show an organism-created construction is causally necessary,
transfers to evaluator-private novelty, and survives independent change of
address, value, segmentation, and instruction/boundary identity. It must beat
equal total-cost controls that receive the same raw medium, not merely weaker
hand-crafted baselines. A number without independent construction, retirement,
and hostile re-encoding is **VALID NEGATIVE**.

## Landing protocol

Workers edit only their assigned source, CSV, and report. Every landing must
fresh-build from source, selftest, deterministically replay, record exact
charged work, test causal ablation and false/shuffled evidence, and declare
the remaining human-owned layer explicitly. The coordinator alone settles this
master, `RESEARCH_TOC.md`, and `INDEX.md` using **POSITIVE**, **VALID
NEGATIVE**, or **BLOCKED**.

## Coordinator verdict (2026-07-16)

Fresh independent coordinator builds, selftests, executions, and byte-identical
CSV comparisons pass for AD1–AD3. Each has a real bounded causal effect:
macro configuration improves resource and ablates exactly; an ecology outperforms
ordinary random/replay controls; and a transducer migrates function through
combined hostile transport with exact ablation and false-evidence rollback.

None is open-ended organism construction. AD1's supposed interpreter is a
configuration inside a fixed host decoder and opcode system. AD2's challenge
ecology is inside fixed cells, rewrite language, world dynamics, and cadence.
AD3 ties the fixed-decoder and equal-language controls exactly, so it transports
behavior through a supplied micro-language rather than building one. These are
three convergent valid negatives, not failed runs. AD4–AD6 remain blocked.

The next legitimate edge is narrower and harder: derive a *new operational
semantics* from lower-level causal interactions, then demonstrate that the
organism can choose between independently constructed semantics, retire the
bootstrap semantic, and maintain behavior under a private change that breaks
every bootstrap instruction/boundary identity. The experiment must compare
against an equally expressive fixed semantics and charge all construction; a
larger host language or a preinstalled meta-VM is not progress.
