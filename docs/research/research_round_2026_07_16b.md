# Research Round 2026-07-16b (Round AE) — operational semantics birth

**Status:** GATED — AE1/AE2/AE3 replayed as valid negatives; AE4–AE6 remain blocked.

**Goal:** Attack the surviving fixed layer directly. An organism must derive
operational semantics from lower-level causal interactions, construct and test
alternatives, select one from earned evidence, and retire the bootstrap
semantics. It may not receive a host VM, high-level opcode meanings, decoder,
genome/component boundary, task family, target, candidate/proposal menu, or
intermediate score. The required result is a *new causal interpretation that
changes what the organism can do*, not an optimized setting within supplied
semantics.

The only fixed exterior is deterministic raw interaction transport, finite
resource accounting, sandbox/provenance, evaluator-private fresh worlds, and
external authority/safety. These enforcement conditions may not encode an
organism-level vocabulary. No LLM, language/token prediction, embeddings,
neuro-symbolic machinery, preloaded Rune, solution trace, named curriculum,
or oracle-guided selection is permitted.

## Evidence standard

Every claimed semantic must be represented as organism-owned mutable matter,
be executable using only lower-level interactions, have a causal lineage from
earned observations, beat equal-total-cost raw/random/replay/static and
equally expressive fixed-semantic controls, and be necessary by ablation.
Bootstrap semantics must be causally retired. A private evaluator must then
destroy all bootstrap instruction, address, value, and boundary identity. If
the organism simply uses a supplied decoder, transition table, probe grammar,
or semantic comparison form, the verdict is **VALID NEGATIVE**.

## Landing protocol

Each worker edits only its assigned source, result CSV, and report. A landing
must fresh-build, selftest, deterministically replay, record all charged work,
include ablation plus false/shuffled-evidence attacks, identify its remaining
human-owned layer, and label **POSITIVE**, **VALID NEGATIVE**, or **BLOCKED**.
The coordinator independently replays and alone updates this master, the TOC,
and the index.

## Coordinator verdict (2026-07-16)

Fresh independent coordinator builds, selftests, executions, and byte-identical
CSV comparisons pass for AE1–AE3. The work strengthens the evidence boundary:
raw-trace memory can produce a large ablatable gain; competing tapes can commit
and retire under real versus false lineage; and causal records can restore
behavior through wholesale identity destruction.

It does not establish semantic birth. AE1 writes values into host-defined trace
and prediction slots. AE2's exact tie to fixed semantics means its whole
selection/retirement story is expressible inside a supplied semantic grammar.
AE3's exact tie to both fixed decoder and equal language proves recovery is
transport through host `execute`, not organism-owned meaning. These are valid
negatives, not failed agents. AE4–AE6 remain blocked.

The next valid attack must remove the host's observational and comparison
semantics, not merely its instruction names. An organism should construct
closed causal sensorimotor loops in a raw interaction field, invent an
invariant that serves as its own prediction/control criterion, and make that
invariant causally useful in evaluator-private worlds. The audit must compare
against a fixed equally expressive invariant and demonstrate that the
organism's invented invariant—not a host score/trace/probe form—is necessary.
