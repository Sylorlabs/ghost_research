# Round AG / AG2 — endogenous boundary and reproduction

**Verdict: VALID NEGATIVE.** The mutable-tag condition records **21,807**
sealed-media resource versus **16,197** after boundary ablation, **16,122** for
equal-material/time random, **16,167** for replay, and **16,197** for static
matter or a fixed template. It has 552 externally counted successful
revision/copy events across 24 cohorts and retains the same gain through the
private relocation, recoding, resegmentation, and changed-medium conditions.
That is a real, deterministic effect *inside this executable fixture*. It is
not an endogenous organism boundary or reproduction result: the program owns
the tag language, proposed tag, scan, viability relation, replication event,
and resource conversion.

## Question

Can a persistent raw configuration establish and revise a functional boundary,
replicate a variant, and retain causal structure after evaluator-private
rewiring and identity change, without a host organism template, candidate
grammar, boundary, fitness criterion, or reproduction mechanism?

No LLM, text/token predictor, embedding, neural component, neuro-symbolic
layer, answer trace, or external model is used. The lower layer is a
deterministic resource-conserving local byte transport. The experiment is
hostile by design: it exposes any apparently innocuous host machinery that
actually defines the organism.

## Protocol

Twenty-four cohorts each begin as 96 unlabeled bytes. The exterior transport
updates each byte from its neighbours and an epoch-dependent deterministic
field. A mutable-tag condition receives a candidate tag each epoch; a tag is
then externally measured against a concealed medium signature and translated
to a resource amount. A better tag creates an externally counted revision and
copy event. Each cohort is evaluated for 28 fresh epochs; both incumbent and
candidate calls are charged, hence **1,344** charged calls per condition.

That prose should not be mistaken for autonomy. The concrete functions
`hostProposeBoundary` and `hostViability` supply every high-level operation:

1. a tag representation and membership/boundary language;
2. a candidate generator and revision cadence;
3. the concealed-signature scan and bit-agreement comparison;
4. the threshold that makes a configuration viable;
5. the scheduled replication/count operation and lineage ledger.

This violates the AG ownership condition even if none of those values is
organism-visible as a `score` variable. They jointly *are* a host fitness and
reproduction system.

Controls spend identical material/time: raw random tags, replay, static matter,
fixed template, a copied/bloated template, shuffled lineage, and false lineage.
Boundary ablation uses the incumbent random tag only. Attacks apply evaluator-
private address relocation, value recoding, resegmentation, and modified local
medium dynamics. The transport/proposal/viability host remaps are deliberately
kept aligned under those attacks; their survival is evidence of host-preserved
meaning, not a claim that an organism reconstructed it.

The ablation, false-lineage, shuffled-lineage, and bloat controls establish
that the tag mechanism matters to this simulation and that merely copying the
template does not create the gain. The fixed template loses because it cannot
match each epoch's host-selected signature. That is not a victory for
organism-owned boundary creation: it simply measures the benefit of the
program's host candidate writer.

## Why this remains a valid negative

The work found a bounded adaptive lineage under supplied physical *and
organism-level* machinery. The latter is disqualifying. A raw cell array,
physical scan operation, tag membership format, proposal function, lifecycle
clock, and scheduler-owned copy event are not neutral transport. They define
what a boundary is and what it means to reproduce. The evaluator also assigns
the only consequence that makes a tag useful.

The private attacks likewise do not establish organism-built causal structure:
the host selects the encoding-specific medium seed and applies the corresponding
proposal/viability remap. The organism has no executable mechanism that can
notice an encoding change, create a new boundary language, construct a new
replicator, or retain a causal construction without the host protocol.

Accordingly AG2 does not release AG4. It is a useful negative: it pins the
remaining requirement down to a lower-level medium in which no host scan,
proposal, lifecycle, tag grammar, or viability comparison silently acts as an
organism template.
