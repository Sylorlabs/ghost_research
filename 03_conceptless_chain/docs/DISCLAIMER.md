# Disclaimer — Thread 03: Conceptless Std-Only Invention Chain

**This is the lineage that led directly to DomainSpec.** These documents
are historically accurate but the framing of "invention" was later tightened.

## What was true when written

- Gen0/1/2 engines use only Zig stdlib — no VSA, no hypervectors — and are the first
  engines to produce measurable program quality improvements without semantic scaffolding
- Score progression 291 → 294 → 296 is a real measured result
- The conceptless approach confirmed that VSA is not necessary for improvement

## What was later revised

- **"Invention" definition was informal.** The strict INVENTION definition used in Thread 04+
  (quality strictly beats all prior champions on held-out seeds, peer-distance confirmed)
  was not applied here. The score improvements may reflect anchor overfitting.
- **Remix, not invention.** A 2026-05-19 empirical test confirmed the system is a remixer
  over a fixed 20-concept basis. It does not invent new concepts — it recombines existing ones.
- **These engines were not tested for bijectivity or PractRand quality.** The output programs
  were never run through Z3 or PractRand. Quality is measured by composite fitness only.

## Safe to use these docs for

Understanding the pre-DomainSpec baseline and the motivation for the strict
INVENTION definition adopted in Thread 04.
