# Validation-v7 accountable provenance inbox

This inbox accepts only the thirteen files named by the frozen accountable
provenance protocol. It remains empty until the corrected v2 bundle exists,
the sponsor trust root has been verified out of band, and curator, reviewer,
and external-log identities have been enrolled.

A complete gate proves accountable signed commitments and governed ordering.
It does not cryptographically prove social independence or rule out off-system
collusion, and it never authorizes payload decryption.
