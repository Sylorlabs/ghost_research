# Foundry readiness iteration 5.21

Phase 132 answers a deliberately narrow feasibility question. A separately
named, evaluator-authored fixed-width tensor language plugs into the
byte-exact upstream Enumo core. Its frozen size-3 and size-4 workloads contain
38 and 136 expressions and yield 11 plus 7 learned rules. All 18 rules pass
the runner's exhaustive five-vector check and a separately implemented parser
and scalar-domain verifier covering 1,176 lane evaluations. Nine hostile rule
classes are rejected.

This is not frozen Boolean A7. The tensor grammar, value type, operators,
samples, and workload recipe were supplied by the evaluator. It neither
constructs its own tool grammar nor lowers the 23 real framework graphs.

Phase 133 tests whether the feasible mechanism is useful. Before its runner
existed, it froze every size-5 expression generated by the declared grammar:
3,339 held-out expressions, with no outcome-based selection. It also froze a
13-rule fixed algebraic portfolio and an independent `[-5,5]` scalar semantic
check. Both portfolios terminate naturally, remain sound, and stay far below
the 512-state ceiling.

The learned portfolio obtains **0** strict atom-cost wins. The fixed portfolio
obtains **736**; **2,603** expressions tie. Learned rules simplify 1,511
inputs, but the fixed rules simplify 1,945. The learned basis therefore
rediscovered useful identities without adding a cheaper held-out capability
over the fixed baseline.

This is genuine progress because it separates two claims that were previously
blurred:

1. Upstream Enumo can operate inside a supplied tensor algebra: established.
2. Its learned rules beat a strong fixed portfolio or reduce grammar
   hand-holding: not established.

Readiness remains `5/6`, P1 remains `3/4`, production integration remains
`6/10`, and validation-v6 remains sealed. The next justified Enumo-adjacent
experiment is not a larger handwritten grammar. It is a pre-frozen
grammar-construction falsification: derive typed forms from calibration traces
and require a candidate-only held-out advantage over the same fixed baseline.
