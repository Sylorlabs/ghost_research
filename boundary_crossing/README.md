# boundary_crossing

**A new chapter, not a continuation of closure-characterization.** `sparse_poly_discovery/` proved (and
`docs/research/inner_forge.md` + `clone_lattice.md` + `kary_frontier.md` mapped) the terminal result: a
*purist* symbolic forge is confined to its substrate's closure — it composes, it does not cross algebraic
families. The only genuine escape the Closure Principle allows is to **inject a generator from a source richer
than any fixed substrate.**

This project does exactly that, kept honest by the project's certifier discipline (held-out accuracy +
irreducibility). It is the **FunSearch architecture** (external source + verifier) in its most *purist* form:
the out-of-substrate "source" is **real mathematics**, and the "verifier" is the closure diagnostic, not an LLM.

## Why this is a real boundary crossing

The Closure Principle says invention = injecting an out-of-closure generator. Real mathematical structure
(primality, the sieve, divisibility, the Möbius function) is **not** generated by any fixed algebraic family —
it is out-of-closure by construction. So pointing the certifier at real mathematical targets, and keeping only
the generators that *provably* escape the algebraic closure, is a genuine, certified crossing — the first thing
in the whole research arc that escapes a closure rather than relocating it.

## What is established

The engine exists end-to-end and is **source-agnostic**: the `inject → certify → promote` loop is the invariant,
and the out-of-substrate **source is swappable** — number theory (`world_injection` / `invention_engine`), a
verifiable external unknown (`superopt`), real data (`real_data`), or an unreliable proposer like an LLM
(`certifier_filter`). In every case the certifier separates **certified invention** from recombination with a
receipt, which is the original goal: *more than recombination, and prove which is which.*

The certifier's two gates, and what each is for (learned the hard way in `certifier_filter`):
- **IRREDUCIBILITY** (held-out R² from the library) rejects *dressed-up recombinations* — but is blind to garbage
  (a random feature is trivially irreducible).
- **ESCAPE, replicated on two independent held-out folds, above the noise floor** rejects *hallucinations* —
  a spurious single-fold gain does not replicate. This is what makes an unreliable rich source usable.

## Roadmap

The architecture is done; the obvious extensions, each the same loop with a richer source: wire a **live LLM** as
the `certifier_filter` proposer; scale `superopt` to wider words via the **Z3 CEGIS** verifier in
`../04_verified_synthesis`; point the loop at an **open combinatorial conjecture** for a genuinely-unknown result.

Theory / prior art: FunSearch (Romera-Paredes et al., DeepMind 2023); AlphaEvolve (2025); the Closure Principle
(`../CLOSURE_PRINCIPLE.md`) and `../RESEARCH_QUESTIONS.md` §J (the external-ingredient path).

what independent witnesses verify, abstain otherwise, prove on demand** — a *knower*, not a transformer *guesser*.
